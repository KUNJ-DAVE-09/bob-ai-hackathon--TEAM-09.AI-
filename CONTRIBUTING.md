# Contributing

This repository is a hackathon submission created from the `bob-ai-hackathon-submission-template`.

## Submission Instructions

1. Ensure `submission.yaml` is fully filled with no blank required fields.
2. Ensure `README.md` contains no `[placeholder]` text.
3. Ensure `docs/setup-guide.md` has been tested end-to-end.
4. Ensure `demo/demo-video-link.txt` contains a real, accessible video URL.
5. Ensure `demo/screenshots/` contains at least 3 screenshots.
6. Ensure `presentation/slides.pdf` or `slides.pptx` is present.
7. Push all changes and confirm the GitHub Actions **Validate Submission** workflow is green.
8. Submit the repository URL via the hackathon entry form before the deadline.

Do not modify `.github/workflows/validate.yml`.
